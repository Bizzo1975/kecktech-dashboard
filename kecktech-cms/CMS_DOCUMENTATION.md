# Content Management System Documentation

Guide for managing content on the Kecktech IT Service & Support website.

## Accessing the Admin Panel

1. Navigate to `/admin/login`
2. Enter your admin credentials
3. You'll be redirected to the dashboard

## Managing Services

### Creating a New Service

1. Go to **Services** in the sidebar
2. Click **New Service** button
3. Fill in the form:
   - **Title**: Service name (e.g., "Cybersecurity")
   - **Slug**: URL-friendly identifier (auto-generated from title)
   - **Description**: Short description (shown in listings)
   - **Content**: Full detailed description
   - **Category**: Select or leave blank
   - **Price**: Optional pricing information
   - **Image URL**: Link to service image
   - **Status**: Active, Coming Soon, or Archived
   - **Featured**: Check to feature on homepage
   - **Display Order**: Number for sorting (lower = first)
   - **Meta Title**: SEO title (optional)
   - **Meta Description**: SEO description (optional)
4. Click **Create Service**

### Editing a Service

1. Go to **Services** in the sidebar
2. Find the service you want to edit
3. Click the **Edit** icon (pencil)
4. Make your changes
5. Click **Save Changes**

### Deleting a Service

1. Go to **Services** in the sidebar
2. Find the service you want to delete
3. Click the **Delete** icon (trash)
4. Confirm deletion in the dialog

### Previewing a Service

1. While editing a service, you can preview it
2. Click **Preview** to see how it will look on the website
3. The preview shows the service as visitors will see it

## Service Status

- **Active**: Service is live and visible on the website
- **Coming Soon**: Service is visible but marked as coming soon
- **Archived**: Service is hidden from public view

## Best Practices

### Writing Service Descriptions

- Keep descriptions clear and concise
- Use bullet points for features
- Include benefits, not just features
- Use professional language

### SEO Optimization

- Use relevant keywords in titles and descriptions
- Write unique meta descriptions for each service
- Use descriptive image alt text
- Keep URLs (slugs) short and descriptive

### Images

- Use high-quality images
- Recommended size: 1200x630px for featured images
- Use WebP or JPEG format
- Optimize images before uploading
- For now, use image URLs (file upload coming soon)

## User Management

### Viewing Users

1. Go to **Users** in the sidebar
2. View all admin users and their roles

### User Roles

- **Admin**: Full access to all features
- **Editor**: Can create and edit content
- **Viewer**: Read-only access (future)

## Troubleshooting

### Can't log in?
- Verify your email and password
- Check that your account is active
- Contact system administrator

### Service not appearing?
- Check service status (must be "Active")
- Verify the service is saved
- Clear browser cache

### Images not loading?
- Verify image URL is correct
- Check that image is publicly accessible
- Ensure URL uses HTTPS
