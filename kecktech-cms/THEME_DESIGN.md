# Professional IT Business Theme & Design System

## Overview

This document outlines the professional IT business theme and design system implemented for the Kecktech website, based on modern web design trends and professional IT service company best practices.

## Color Palette

### Light Mode
- **Primary**: `#0066ff` - Professional Tech Blue (trust, technology, reliability)
- **Accent**: `#0ea5e9` - Electric Blue (innovation, energy)
- **Background**: `#ffffff` - Pure White
- **Foreground**: `#0f172a` - Deep Slate (professional text)
- **Secondary**: `#f8fafc` - Cool Gray (subtle backgrounds)
- **Muted**: `#f1f5f9` - Light Gray (borders, subtle elements)

### Dark Mode
- **Primary**: `#3b82f6` - Bright Tech Blue
- **Accent**: `#06b6d4` - Cyan Blue
- **Background**: `#0a0f1e` - Deep Navy (professional dark)
- **Foreground**: `#f1f5f9` - Light Slate
- **Card**: `#1a1f2e` - Dark Card Background
- **Border**: `#334155` - Subtle Border

## Design Principles

### 1. Professional Gradients
- **Primary Gradient**: `linear-gradient(135deg, #0066ff 0%, #0052cc 100%)`
- **Accent Gradient**: `linear-gradient(135deg, #0ea5e9 0%, #0284c7 100%)`
- **Hero Gradient**: Multi-stop gradient for dynamic hero sections

### 2. Glassmorphism Effects
- **Glass**: Subtle backdrop blur with transparency
- **Glass Subtle**: Lighter effect for cards
- **Glass Strong**: More pronounced effect for CTAs

### 3. Typography
- **Headings**: Bold, modern sans-serif with gradient text support
- **Body**: Clean, readable with proper line-height
- **Gradients**: Text gradients for emphasis on key phrases

### 4. Spacing & Layout
- **Section Padding**: Consistent `section-padding` utility class
- **Container**: Max-width containers for optimal readability
- **Grid System**: Responsive grid layouts for services and content
